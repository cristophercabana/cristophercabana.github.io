Primer Writeup - Reversing

Challenge: CrackMe - Password Validation

Dificultad: Fácil

Categoría: Reversing

Análisis inicial

Al ejecutar el programa, se observa que al introducir una contraseña incorrecta aparece el mensaje "Password Trash". Esto sugiere que el programa valida la entrada del usuario contra un valor interno.

Búsqueda de strings

Se utilizó Cheat Engine para buscar el string "Password Trash" en memoria. Se encontró una referencia estática (en verde), indicando que el string está almacenado en el binario.

Siguiendo las referencias, se llegó al siguiente loop:

mov al, [ecx]
inc ecx
test al, al
jne ...

Este loop recorre un string byte por byte hasta encontrar un 0, por lo que no corresponde a la validación, sino a una rutina interna.

Identificación del flujo principal

Siguiendo el stacktrace se llegó a la función relevante dentro del binario.

Análisis de la validación

call GetDlgItemTextA
push "SuperPass"
lea eax, [ebp-104]
push eax
call lstrcmp
or eax, eax
jne fail

Interpretación

  • GetDlgItemTextA: obtiene el input del usuario y lo guarda en memoria
  • lea eax, [ebp-104]: obtiene la dirección del buffer
  • push "SuperPass": prepara la cadena de comparación
  • lstrcmp: compara ambas cadenas
  • jne: salta si son diferentes

Conclusión

La contraseña correcta es:

SuperPass

Al introducirla, el programa muestra el mensaje "Password Good".
